## Запуск

Требуется JDK 21. В IntelliJ: открыть проект, выбрать JDK, отметить src как Sources Root. Каждая часть запускается своим main. Рабочая папка — корень этого проекта.

Из PowerShell:

```powershell
$sourceFiles = @(Get-ChildItem src -Recurse -Filter *.java | ForEach-Object FullName)
javac -encoding UTF-8 -d build @sourceFiles
java -cp build part1_array_syntax.Main
java -cp build part2_array_handling.Main
java -cp build part3_contacts.Main
```

## Что показать на защите

Покажи создание массивов трёх видов, пять типов элементов, length, обращение по индексу, три способа обхода и ошибку неверного индекса. Затем ввод, случайный массив, сумму, максимум, поиск и меню контактов.

## Как объяснить

Массив имеет фиксированную длину; допустимые индексы — от 0 до length-1. Линейный поиск обходит элементы до первого совпадения и возвращает индекс либо -1. Максимум начинается с первого элемента, поэтому корректно работает и для полностью отрицательных массивов. Для суммы используется long.

## Возможные вопросы

- **Чем размер массива отличается от количества контактов?** Размер — вместимость, count — число действительно добавленных элементов.
- **Что означает DELETED?** Логическое удаление: слот остаётся, но прежний текст заменяется.
- **Почему enhanced for не даёт индекс?** Он предназначен для обхода значений, индекс в нём не объявляется.
